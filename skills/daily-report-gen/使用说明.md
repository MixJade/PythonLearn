# 日报周报生成工具 - 使用说明

## 前置依赖

| 依赖 | 要求 |
|-----|------|
| Git | 已安装并配置到 PATH |
| Python | 已安装并配置到 PATH |

## 一、配置

在 skill 目录下新建 `config/config.json`：把 `example` 目录里的 `样例配置.json` 复制一份，改名为 `config.json` 放进去即可。

打开后改两处：

| 字段 | 改成什么 |
|-----|---------|
| `author_name` | 你的 Git 提交人用户名（要和 `git log` 里的作者名一致） |
| `projects` | 你要统计的模块名，以及该模块下的仓库路径 |

关于 `projects`：

- 一个模块可以配多个仓库路径，脚本会逐个查完再合并
- 模块名就是以后对 AI 说"某某的日报"里的"某某"
- Windows 路径要写成双反斜杠，例如 `E:\\MyCode\\JavaLearn`

## 二、怎么用

在 WorkBuddy 里直接说话即可，例如：

- `编写项目管理的日报`
- `生成项目管理的周报`
- `编写项目管理7月8日后的日报`

说日报还是说周报都一样，都会同时生成日报和周报。配置里配了多个模块时，要说清是哪个模块。

也可以自己跑脚本：

```bash
python GetPrjGitRecords.py -a config/config.json -b 项目管理 -s 2026-07-01
```

`example` 目录里的 `样例.cmd` 是现成的命令示例，复制一份改改就能用。

| 参数 | 必填 | 说明 |
|-----|------|------|
| `-a, --config` | 是 | 配置文件路径 |
| `-b, --module` | 是 | 模块名；不填会提示必须指定 |
| `-s, --start-date` | 否 | 起始日期（YYYY-MM-DD），不填默认近 7 天 |

`-s` 也可以传 `_`，脚本会停下来问你日期，直接回车就用默认值（会先把默认日期算好显示出来）：

```bash
python GetPrjGitRecords.py -a config/config.json -b 项目管理 -s _
```
