# 日报周报生成工具 - 使用说明

## 重要更新 v3.1

**命令行参数化**：脚本已改为命令行参数输入，无需交互式输入

**相对路径化**：所有路径改为相对路径，方便在不同电脑上使用

## 前置依赖

| 依赖 | 要求 | 说明 |
|-----|------|-----|
| Git | ✅ 必须 | 需安装并配置到PATH环境变量 |
| Python | ✅ 必须 | 需安装Python并配置到PATH环境变量 |
| WorkBuddy | ✅ 必须 | AI助手运行环境 |

## 快速开始

### 1. 配置项目

在skill目录下创建 `config/config.yaml`：

```
skill目录/
├── config/
│   └── config.yaml
└── ...
```

配置文件内容：

```yaml
author_name: 你的Git用户名

projects:
  项目管理:
    paths:
      - D:\proj\frontend\project-mng-ui
      - D:\proj\backend\jdk21\ms-project-mng-base
```

### 2. 使用AI生成日报

在WorkBuddy中输入以下指令：

```
编写项目管理的日报
编写项目管理7月8日后的日报
```

## 脚本使用

### 命令行参数

```bash
python GetPrjGitRecords.py -a <提交人> -s <起始日期> -r <仓库路径1> <仓库路径2> ...
```

| 参数 | 必填 | 说明 |
|-----|------|------|
| `-a, --author` | 否 | 提交人名称，不指定则查询所有 |
| `-s, --start-date` | 否 | 起始日期（YYYY-MM-DD），不指定默认7天前 |
| `-r, --repos` | ✅ | 仓库路径列表，至少一个 |

### 示例

```bash
# 指定提交人和日期
python GetPrjGitRecords.py -a 张三 -s 2026-07-01 -r "D:\proj\ui"

# 仅指定日期
python GetPrjGitRecords.py -s 2026-07-01 -r "D:\proj\ui" "D:\proj\api"

# 使用默认日期，查询所有提交人
python GetPrjGitRecords.py -r "D:\proj\ui"
```

## 功能特点

| 特性 | 说明 |
|-----|------|
| 日期解析 | 支持"7月8日后"、"2026-07-08"等多种格式 |
| 多仓库支持 | 一个项目可配置多个Git仓库路径 |
| 自动去重 | 同一提交在多分支只显示一次 |
| 桌面输出 | 自动在桌面创建"日报+日期"文件夹 |
| 命令行参数 | 改为命令行参数输入，无需交互 |

## 工作流程

1. **检查配置文件** - `./config/config.yaml`，不存在则终止
2. 读取配置，获取项目名称和仓库路径
3. 解析日期参数
4. **执行Python脚本**（命令行参数方式）
5. 脚本自动生成提交记录文件到桌面
6. AI基于脚本输出生成日报周报
