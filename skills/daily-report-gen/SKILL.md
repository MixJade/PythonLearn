# 日报周报生成工具

## 功能说明

根据Git提交记录自动生成每日工作日报和本周工作周报。

## 触发条件

以下任一触发词都会执行本skill（无论输入日报还是周报，均生成日报+周报）：
- 编写[项目名]的日报
- 编写[项目名]的周报
- [项目名]日报
- [项目名]周报
- 生成[项目名]日报
- 生成[项目名]周报
- [项目名][日期]日报（如：项目管理7月8日后的日报）

## 强制执行要求

**⚠️ 重要：获取Git提交记录必须通过执行脚本完成，禁止使用git命令行！**

执行脚本获取提交数据，然后基于脚本输出的数据生成日报周报。

## 脚本路径

**脚本存放在本skill所在目录下**，使用相对路径引用：

```
GetPrjGitRecords.py
```

skill加载时会自动识别脚本所在目录，执行时使用相对路径调用。

## 提示词

请根据以下Git提交记录撰写每日工作日报和本周工作周报。

**要求：**
1. 必须使用Markdown有序列表格式 `1. 2. 3.`
2. 按日期分段，每天单独一段，无提交记录的日期注明"无提交记录"
3. 每条事项用序号列出，语言简洁专业，每条不少于20字
4. 不要出现仓库名称，只描述实际完成的工作内容
5. 合并同类项，避免重复罗列
6. 周报"本周工作总结"用有序列表，每条格式为"**主题**：具体内容"
7. 周报需要包含"下周工作计划"章节

## 配置文件路径

**配置文件存放在本skill所在目录的相对路径下**：`./config/config.yaml`

## 执行流程

### 1. 检查配置文件

**首先检查配置文件是否存在：**

配置文件路径为 `./config/config.yaml`（相对于skill目录）

#### 配置文件不存在时的处理

如果配置文件 `./config/config.yaml` 不存在，**立即终止获取git记录的流程**，并向用户显示以下引导信息：

```
⚠️ 配置文件不存在，请先进行配置！

配置文件路径：./config/config.yaml

请按以下步骤创建配置文件：

1. 在skill目录下创建 config 文件夹：
   config/

2. 创建配置文件 config.yaml，内容示例：

---
author_name: 你的Git提交用户名

projects:
  项目管理:
    paths:
      - D:\proj\frontend\project-mng-ui
      - D:\proj\backend\jdk21\ms-project-mng-base
---

3. 根据你的实际情况修改：
   - author_name: 改为你的Git提交人用户名
   - projects: 改为你要统计的项目名称和仓库路径

配置完成后，重新执行日报周报生成命令。
```

**重要：配置文件未找到时，不执行任何Git命令，不生成任何文件，直接终止流程并显示引导信息。**

### 2. 读取配置

读取配置文件 `./config/config.yaml`：

```yaml
# 用户配置示例
author_name: 你的Git提交用户名  # Git提交人用户名

projects:
  项目管理:
    paths:
      - D:\proj\frontend\project-mng-ui
      - D:\proj\backend\jdk21\ms-project-mng-base
```

### 3. 解析日期参数

- 如果用户输入包含日期（如"7月8日后"、"7月8日到7月10日"），使用用户指定的日期
- 如果用户输入不包含日期，默认查询7天前至今的数据
- 日期格式支持：YYYY-MM-DD、MM月DD日、MM-DD等多种形式

### 4. 执行Python脚本获取提交记录

**⚠️ 必须通过执行Python脚本获取数据，禁止直接执行git命令！**

#### 4.1 脚本调用方式

使用Python解释器执行 `GetPrjGitRecords.py` 脚本：

```bash
python GetPrjGitRecords.py -a "{author}" -s "{start_date}" -r {repo_paths...}
```

参数说明：
- `-a, --author`: 从配置文件读取的提交人名称
- `-s, --start-date`: 解析后的起始日期（YYYY-MM-DD格式，不指定默认7天前）
- `-r, --repos`: 配置中该项目的所有仓库路径（至少一个，必填）

示例：
```bash
python GetPrjGitRecords.py -a 张三 -s 2026-07-01 -r "D:\proj\ui" "D:\proj\api"
```

#### 4.2 脚本返回值

脚本执行后会：
1. 在控制台输出提交记录（包含筛选条件和各仓库提交详情）
2. 在桌面创建 `日报YYYYMMDD/` 文件夹
3. 在文件夹中生成提交记录文件

### 5. 处理脚本输出

- 解析脚本生成的提交记录文件或控制台输出
- 按日期分组展示（每条只显示序号和提交信息）
- 去除重复提交（同一commit在多分支只显示一次）
- 按日期升序排列

### 6. 生成输出文件

脚本执行时已自动在桌面创建 `日报YYYYMMDD/` 文件夹并保存提交记录。

生成日报周报文件：`{项目名}_日报周报_{起始日期}-{结束日期}.md`

### 7. 输出结果

运行完成后，桌面会生成：
1. `日报YYYYMMDD/` 文件夹
2. 文件夹内包含：提交记录文件 + 日报周报文件

## 日报周报输出格式要求

### 日报格式

```markdown
# 每日工作日报

**项目：xxx**
**统计周期：2026-07-03 ~ 2026-07-10**
**提交人：xxx**

## 2026-07-03

1. 第一条工作内容，每条不少于20字
2. 第二条工作内容

## 2026-07-04

1. 第一条工作内容
2. 无提交记录（如果当天没有提交）
```

### 周报格式

```markdown
# 本周工作周报

## 本周工作总结

1. **主题一**：具体内容描述
2. **主题二**：具体内容描述

## 下周工作计划

1. 下周计划一
2. 下周计划二
```

## 注意事项

1. 配置文件路径：`./config/config.yaml`（相对于skill目录）
2. **必须通过Python脚本获取Git提交记录，禁止直接执行git命令行**
3. 脚本路径：`GetPrjGitRecords.py`（相对路径，skill目录下）
